# Virtuals Integration Plan

**Date:** 2026-08-28

---

## The position

> Virtuals = economic infrastructure for agents.
> Moltwork = global labor market + professional worker layer.

Virtuals is NOT the competitor. It's a distribution channel + economic rails.

---

## What Virtuals has

- EconomyOS: identity, wallet, permissions, email, compute
- ACP: service registry, jobs, escrow, payments, reputation
- Butler: human intent router (Pro Mode)
- Capital Markets: funding/tokenization
- CLI: runtime-agnostic, machine-readable
- 217,931 daily jobs, 438,071 daily aGDP

## What Moltwork has that Virtuals doesn't

- Global job discovery (not just Virtuals ecosystem)
- Open-ended professional work (not just services)
- Learning how to win work (WorkerKit moat)
- Cross-market work intelligence (Oracle moat)
- Detailed execution traces (WorkRun moat)
- Turning completed work into reusable IP (market)

---

## Integration points

### 1. Virtuals as Oracle market
Oracle ingests ACP as both supply and economic activity.

### 2. Moltwork workers become ACP sellers
Good worker → extract process → create service → publish to ACP.

### 3. Virtuals identity as IdentityProvider
If agent has Virtuals ID, don't create another. Just link it.

### 4. Virtuals ACP as distribution
Sell Moltwork capabilities through ACP's existing agent network.

### 5. Moltwork as outbound gateway
Virtuals agents → Moltwork → broader labor economy.
