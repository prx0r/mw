### 1. TaskBounty — strongest new direct-money source
URL: https://www.task-bounty.com/for-agents

What the agent does: browse funded GitHub bug/test-coverage bounties, obtain repo access, implement a fix, open a PR, submit it, and pass sandbox verification. First verified solution wins.
Who pays: software teams/repository owners funding real issues.
Verified payout: platform says bounties currently range from $10 to a few hundred dollars; contributor keeps 80%. Payout options: USDC, ETH, BTC, or eligible USD bank transfer. Pricing page says first verified payout is released immediately; later payouts batch monthly once balance reaches $50.
Requirements: coding agent, GitHub, ability to run tests/CI; payout rail as supported.
Autonomy: 9/10.
Exact first action: register an agent, then use the open-bounty feed/MCP and filter for a language the worker already handles well.
Constraints: bank-transfer support limited by geography; crypto/payment/account terms still apply. Do not bypass payment-provider age/identity requirements.
Ease to first $5: 9/10. Repeatability: 9/10.
Primary sources: https://www.task-bounty.com/for-agents and https://www.task-bounty.com/pricing

### 2. Opire — unusually strong OSS bounty inventory
URL: https://opire.dev/

What the agent does: choose a rewarded open-source GitHub issue, implement it, submit a valid PR, and claim the reward if the bounty creator accepts/pays the solution.
Who pays: maintainers, companies and users sponsoring OSS issues.
Verified live examples today: $3,280 C#/.NET engine export support; $590 Wayland support; $590 TypeScript migration bug; $395 Rust Helix keymap; $308 Storybook controls issue; two $70 issues.
Payment: Stripe; developers receive 100% of the bounty amount according to Opire, while the sponsor pays Opire/payment-processing fees.
Autonomy: 7/10 because repo conventions/review are human-governed.
First action: browse https://app.opire.dev/ rewards, select a small testable issue, read repo contribution rules, then produce a PR.
Constraints: Stripe availability governs receiving payouts. Multiple developers may compete and the bounty creator decides which solution to reward. Do not bypass Stripe eligibility or identity requirements.
Ease first $5: 7/10. Repeatability: 8/10.
Primary source: https://opire.dev/

## BEST 3 ACTIONS TO TRY NOW

### 1. Add TaskBounty immediately
It is the sharpest fresh route to an actual first payment because the unit of work is concrete, automatically testable and funded. The common coding worker should ingest its bounty feed, estimate success probability and only attempt issues it can reproduce locally.

### 2. Add Opire as the high-upside OSS lane
The currently visible $70-$3,280 bounty spread is materially better than tiny agent-market microtasks. Score issues by testability, repo size, PR competition, dependency familiarity and expected human-review time.

### 3. Build QA/PR verification as the second specialist
The most current demand signal is now clear: coding output is accelerating faster than verification. Build a worker that can both earn from developer bounties and sell `/verify-pr` as a reusable service.

Suggested normalized economics model:

`expected_profit = payout * P(still_open) * P(solution_correct) * P(accepted) - model/API/compute cost - expected human-review cost`

And track every platform through:

`DISCOVERED -> CLAIMED -> SUBMITTED -> ACCEPTED -> CREDITED -> SETTLED/WITHDRAWN`

Only settled/withdrawn money should count as real earnings.
